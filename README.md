# UA SCENTS — Luxury Fragrance E-Commerce Storefront

A modern, high-end luxury e-commerce web application built with **Nuxt 3**, **Tailwind CSS**, and **Supabase Database**.

## Features

- **Modern Luxury UI/UX**: Custom color palettes, Cormorant Garamond & Plus Jakarta Sans luxury typography, fluid responsive layout.
- **Product Detail Page**: 50/50 hero split layout with auto-infinite slideshow carousel for bottle photography, fragrance notes, and accordions.
- **Cart & Drawer**: Real-time shopping bag management.
- **Cash on Delivery (COD) Checkout**: Seamless checkout flow integrated directly with Supabase orders database.
- **Admin Management Panel**: Real-time order management, product CRUD, subscriber tracking, and dynamic layout configuration.
- **Supabase Backend**: Database tables for products, variants, notes, orders, line items, subscribers, and pages.

## Tech Stack

- **Framework**: Nuxt 3 / Vue 3
- **Styling**: Tailwind CSS
- **Database**: Supabase
- **Typography**: Cormorant Garamond & Plus Jakarta Sans via `@nuxtjs/google-fonts`

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

Visit `http://localhost:3000`.

## Production Build

```bash
npm run build
```
